# Brief30 Workfix Sprint

Price: 300,000 KRW

## Short Description

고객 후속 연락, 주간 업데이트, 회의 액션, 반복 CSV 정리처럼 매주 손으로 처리하는 업무 1개를 24시간 안에 작은 자동화와 발송 문안으로 바꿉니다.

## What The Buyer Gets

- 1차 납품: 입금 확인 후 24시간 내
- 입력 범위: 익명화한 CSV, 업무 메모, 고객 후속 연락 목록, 반복 처리 규칙
- 산출물: 우선순위 표, 고객별 후속 메일 초안, 짧은 DM 초안, 담당자별 액션 CSV
- 자동화 범위: 브라우저 또는 로컬 파일로 바로 실행 가능한 작은 변환 흐름 1개
- 인수 노트: 사용 순서, 수정 가능한 입력 컬럼, 재사용 방법
- 수정: 결과 확인 후 1회 반영

## Best Fit

- 고객별 후속 메일을 매주 다시 쓰는 팀
- 회의 후 액션을 CSV나 업무 보드로 옮기는 사람
- 주간 업데이트를 고객/내부용 문안으로 나눠야 하는 컨설턴트
- CRM을 도입하기 전 반복 업무 하나만 빨리 줄이고 싶은 1인/소규모 팀

결제 메모 또는 회신 메시지에 주문번호, 입금자명, 회신 연락처를 남겨주세요. 결제 후 `intake/index.html?offer=workfix`로 아래 정보를 보냅니다.

1. 반복 업무 이름
