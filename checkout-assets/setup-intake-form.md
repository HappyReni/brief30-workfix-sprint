# Brief30 Setup Intake

Use these questions for setup pack and done-for-you buyers.

## Questions

1. 어떤 업무 메모를 가장 자주 정리하시나요?
2. 결과물은 어디에 쓰이나요? 예: 주간보고, 회의록, 고객사 공유, 임원 보고
3. 보고 대상은 누구인가요?
4. 선호하는 톤은 무엇인가요?
5. 반드시 포함해야 할 항목은 무엇인가요?
6. 피해야 할 표현이나 민감한 정보가 있나요?
7. 익명화한 원문 메모를 붙여넣어 주세요.
8. 결과물을 언제까지 받으면 좋나요?

## Handoff note

Please remove names, client identifiers, private numbers, account details, and anything your workplace policy does not allow you to share.

The seller kit also includes `intake/index.html`, which turns these answers into a copyable buyer handoff message.

## Workfix Sprint Questions

1. 자동화하려는 반복 업무 이름은 무엇인가요?
2. 지금은 어떤 입력을 받아 어떤 결과물로 바꾸고 있나요?
3. 익명화한 입력 예시 5-20줄을 붙여넣어 주세요.
4. 원하는 출력 예시를 붙여넣어 주세요.
5. 매주 처리해야 하는 건수는 몇 건인가요?
6. 발송 톤, 금지 표현, 우선순위 규칙이 있나요?
7. 결과물은 이메일, DM, CSV, 보고서 중 어디에 쓰이나요?
8. 24시간 안에 꼭 닫아야 하는 범위와 나중으로 미뤄도 되는 범위는 무엇인가요?
